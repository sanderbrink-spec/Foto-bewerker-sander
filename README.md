# AI Fotograaf Pro

Android Studio project for an offline batch photo editor.

Features:
- Up to 100 photos at once
- One-button batch processing
- Offline processing
- Saves results to Pictures/AI Fotograaf Pro
- Sequential processing to reduce memory pressure

Important:
This project is the Android foundation and batch workflow. The final paid-app-level AI retouching requires local ML models and an Android ML runtime. Those are intentionally not faked here.
